Terminal

Tabs, die bleiben.

Jedes Terminal läuft auf dem Server weiter – Seite zu, Laptop zu, Update eingespielt. Es endet erst, wenn du es schließt.

  • Anheften, ziehen, umbenennen, seitliche Tabs
  • Tastenkürzel: Alt+T, Alt+1…9
  • Nicht-Superadmins ohne sudo/su – technisch gesperrt
Docker & VMs

Jede Sekunde live.

Container öffnen und sofort sehen, was passiert: CPU, Speicher, Netz und Datenträger mit Verlauf. Dazu Logs, Konsole, Dateien – und virtuelle Maschinen mit Konsole im Browser.

  • Container, Images, Netze, Volumes, Compose-Stacks
  • KVM/libvirt: Snapshots, Geräte, ISOs, VNC/SPICE
  • Isolierte Browser-Sitzungen
Sicherheit

Sieh, wer klopft.

Das Angriffs-Radar sammelt Scans nach .env und .git, Exploit-Versuche, falsche Logins und IDS-Treffer – und sperrt Scanner automatisch.

  • fail2ban + Suricata-IDS, Sperren an Firewall und Cloudflare
  • 3 Scans oder 1 Exploit → gesperrt
  • Verlauf bis 30 Tage, Herkunft, Ziele, gesuchte Pfade
Benutzer & Rechte

24 Rechte, fertige Gruppen von „Beobachter“ bis „Docker-Admin“ und eine Übersicht, wer was darf. Der Server prüft jede einzelne Aktion.

  • Kritische Rechte deutlich markiert
  • Passwörter anderer setzt nur der Inhaber
  • Anmeldung mit vorhandenen Linux-Konten

Installation

Eine Zeile. Fertig.

Der Installer richtet Docker ein, lädt das fertige Image und startet alles. Danach http://<server>:8420 öffnen und mit einem Linux-Benutzer anmelden.

curl -fsSL https://raw.githubusercontent.com/slxt47/command-center/main/get.sh | sudo bash
… | sudo bash -s -- --lanaus dem ganzen lokalen Netz erreichbar (LAN, Tailscale, VPN)
… | sudo bash -s -- --nur-lokalnur vom Server selbst – für Reverse-Proxy oder Tunnel
… | sudo bash -s -- --port 9000anderer Port
… | sudo bash -s -- --ohne-schutzohne fail2ban/IDS
sudo command-center updateneueste Version, Einstellungen bleiben
Wichtig: Das Command Center hat Root-Rechte auf dem Server. Nicht ungeschützt ins Internet stellen – LAN/VPN oder HTTPS-Proxy mit Zugangsschutz (z. B. Cloudflare Access) verwenden. Mehr zur Sicherheit
